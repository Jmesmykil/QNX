**Card** — the glass panel that backs About, Settings groups, and any content block on the void.

```jsx
<Card eyebrow="System" title="About Q OS">
  …rows…
</Card>
```

Optional `eyebrow` (mono micro-label) and `title`. Set `accent` to brighten the hairline into a focus ring. Translucent by design — place it over the void or a wallpaper.
