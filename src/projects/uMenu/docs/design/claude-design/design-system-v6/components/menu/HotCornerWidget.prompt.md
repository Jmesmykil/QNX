**HotCornerWidget** — the 96×72 corner hot-zone. Top-left holds the active theme's identity emblem (Q for Glass, ⚡ Neon, 🔥 Dark, ♥ Pastel); tapping it opens the app/recent/search dropdown.

```jsx
<HotCornerWidget glyph="Q" corner="tl" />
```

Accent hairlines run only on the inner edges (toward screen center). Swap `glyph` per theme.
